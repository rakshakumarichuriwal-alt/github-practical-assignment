GitHub – Practical Assignment

Introduction

GitHub is an online platform used by developers to store, manage, and share their code. It helps people work together on projects and track changes in files.

Features of GitHub

1. Code Hosting: Stores project files and source code online.
2. Version Control: Keeps a record of changes made to files.
3. Collaboration: Allows multiple people to work on the same project.
4. Repositories: Provides a place to organize and manage project files.
5. Branching: Allows developers to work on different versions of a project.

Uses of GitHub

- Storing coding projects.
- Sharing technical information.
- Working with other developers.
- Managing software development projects.
- Tracking changes in project files.

Importance of GitHub

GitHub makes software development easier by providing a safe place to store code, manage changes, and collaborate with others.
